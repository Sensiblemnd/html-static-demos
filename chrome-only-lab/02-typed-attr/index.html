Typed attr()

Each row's accent color and load bar come straight from data-accent/data-load HTML attributes via attr(data-accent type(<color>)), no class per row, no inline style, no JavaScript reading the DOM. attr() only ever reads from the exact element it's declared on though, never an ancestor, so the border and the fill bar (two different elements) each carry their own copy of the same two attributes. The percent label is generated the same way, but with plain untyped attr() in content, the one form of attr() that's always worked everywhere. Typed attr() on other properties is Chrome/Edge-only right now, so every row also has a flat fallback color declared first.
