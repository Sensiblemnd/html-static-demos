Chrome-Only Lab

New HTML/CSS from 2025-2026 that only one engine has shipped, or that's only recently crossed into more than one. Unlike the css-lab* series, demos 3 and 4 here use a few lines of JavaScript, they're browser APIs, not CSS, so there's no way around it. Every demo has a real fallback for unsupported browsers, and demos 3-4 need a secure context (https:// or http://localhost), not a file:// page.

01 Customizable Select CSS only A real, fully-accessible <select> restyled with appearance: base-select, rich HTML options, an animated picker. Chrome/Edge 135+, Safari 27+, no Firefox yet; falls back to a plain native select. 02 Typed attr() CSS only A color and a load percentage read straight off data-* attributes into a border-color and a width, no per-row class. Chrome/Edge 133+ only. 03 Geolocation Element needs JS The browser's own permission-request button for location, via the declarative <geolocation> element. Chrome 144+, likely flag-gated even there. 04 Camera/Mic Element needs JS Same idea as demo 03 for camera/mic access, via <usermedia>. Chrome 151+, likely flag-gated even there.
