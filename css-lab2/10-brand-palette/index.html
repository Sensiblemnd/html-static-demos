Brand Palette

Pick one brand color and CSS derives the rest: color-mix() makes a light and dark shade, relative color syntax (rgb(from var(--brand) r 0 0)) peels apart its R/G/B channels, and contrast-color() recomputes readable text independently for all six swatches — no JavaScript, and no color picked by hand except the first one.

  --brand-g: rgb(from var(--brand) 0 g 0);
  --brand-b: rgb(from var(--brand) 0 0 b);
}
