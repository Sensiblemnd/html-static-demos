CSS Variable Slider Lab

Standalone HTML/CSS demos, no JavaScript. Demos 1–8 share one trick: a range slider's thumb gets a view-timeline, a registered @property is bound to it, and moving the slider scrubs that property live. Drag any slider below — requires a Chromium browser with scroll-driven animations support. Demo 9 swaps that trick for :has()-driven swatches and contrast-color(), and needs a very recent browser (Chrome 147+, Firefox 146+, Safari 26+). See docs/ for a note on the source article.

01 Typography Scale One slider drives font size, line height, and letter spacing together from a single interpolated number. 02 Color Channel Mixer Three sliders, three independent view-timelines, mixed live into an rgb() swatch — a from-scratch color picker. 03 Duotone Filter Slider A slider scrubs grayscale, sepia, hue-rotate, and saturate together over a CSS-gradient "photo". 04 Blob Morph All eight border-radius corners interpolate independently, morphing a squircle into a lopsided blob. 05 Tilt Card Two sliders drive rotateX/rotateY and a matching highlight — a joystick-controlled 3D card. 06 Gradient Angle Dial A slider rotates a conic-gradient wheel and a pointer overlay in lockstep, like a color-wheel dial. 07 Equalizer Bars Six sliders, six view-timelines, six bars — showing the technique scales to many simultaneous inputs. 08 Theme Blend A slider crossfades an entire mini UI between dark and light via color-mix() — a live theme toggle, no class swap. 09 Contrast Color Picker Radio-button swatches set --brand via :has(), and contrast-color(var(--brand)) picks black or white text automatically — no view-timeline needed. 10 Brand Palette One picked color, six swatches: color-mix() derives shades, relative color syntax splits out R/G/B, and contrast-color() recomputes readable text on every one.
