Timeline Grid Lab

Nine standalone HTML/CSS demos built on the base Timeline Grid's subgrid technique: a header row and per-row backgrounds all locked to one shared column grid via grid-template-columns: subgrid. No JavaScript anywhere; toggles and interactivity use the checkbox/radio hack, :has(), container queries, and native resize.

01 Overlapping Events Concurrent events get explicit lanes inside .row-data, so a row's height grows to fit however many events overlap. 02 Now Indicator A registered @property percentage drives a looping vertical line sweeping across the grid, simulating a live clock with zero JavaScript. 03 Density Toggle Radio buttons + :has() swap between three pre-built grids at 15/30/60-minute column widths. 04 Dark Mode Toggle Tokens declared once as light-dark(light, dark); radios + :has() force color-scheme to flip them, plus a bonus @supports-gated light-dark() image swap. 05 Responsive Agenda A container query collapses the grid into a stacked agenda list once its container narrows. Drag the native resize handle to see it happen live. 06 Gantt Chart Days on the axis instead of hours, a labeled row per task, and a diamond milestone marker for a single-day event. 07 Contribution Heatmap A GitHub-style activity grid: data-level swaps a color token per square, laid out with grid-auto-flow: column. 08 Resource Scheduler A rooms × hours matrix with a sticky label column that rides along inside the same subgrid as the hour tracks. 09 Kanban Board The subgrid trick turned sideways: rows line up across columns instead of columns lining up across rows.
