CSS 2026 Features Lab

Standalone HTML/CSS demos of CSS that landed since January 2026: text-box-trim/text-box-edge, progress(), and sibling-index()/sibling-count(). No JavaScript. Support varies per demo, see each card and its stylesheet comments; every demo degrades to a plain, still-usable layout where the feature isn't available rather than breaking.

01 Trimmed Type text-box-trim/text-box-edge strip a font's invisible half-leading. A highlight color painted directly behind the text shows its real box shrinking from the top, then the bottom, then both. Chrome/Edge 133+, Safari 18.2+, Firefox 154+. 02 Signal Meter progress() turns a raw 0-100 reading into a 0-1 fraction inside calc(), driving both a meter's fill width and its hue. Chrome/Edge 138+, Safari 26+; Firefox landing in 155. 03 Staggered Reveal A list's entrance stagger reads animation-delay straight off sibling-index(), no hand-written :nth-child() delays. Chrome/Edge 138+, Safari 26.2+; not yet in Firefox. 04 Radial Spokes Eight items space themselves evenly around a circle from sibling-index() and sibling-count() alone, add or remove one and the spacing recomputes. Same support window as demo 03.
