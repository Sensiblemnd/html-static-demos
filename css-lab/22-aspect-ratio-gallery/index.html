Aspect-Ratio Gallery

Four containers, four ways to react to shape instead of width. Each stage below resizes independently — drag its corner and watch what triggers: a compound range, the orientation keyword, the older prefixed min-aspect-ratio syntax, and a single-sided range.

1. Tri-state card

Wide gets a side-by-side layout, square gets a centered circular avatar, tall stacks a full-width image on top. The square band uses a compound query: (aspect-ratio > 4/5) and (aspect-ratio < 5/4).

2. Icon cluster

Reflows to a column in a portrait container using the orientation keyword — the readable alternative to writing out aspect-ratio < 1.

3. Stat panel

The sparkline only appears once the container is wide enough relative to its height to actually be legible, via the prefixed (min-aspect-ratio: 3/2) syntax.

4. Media block

The caption overlays the art in wide containers, but drops to a plain block below it once the shape is too narrow to overlay without obscuring everything: (aspect-ratio >= 4/3).
