Gradual Shrink, Sudden Stack

Two independent rules watch the same box. The padding, the gap between cards, and how rounded their corners are all shrink smoothly the whole time you resize. Separately, once the container gets narrow enough, the three-column grid snaps to a single stacked column. Neither rule knows about the other, they just react to the same container.
