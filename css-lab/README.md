

# CSS Constraint Lab

Each example is a standalone HTML/CSS demo inspired by conditional layout, container-aware design, and the Flexbox Holy Albatross idea. See [`docs/`](docs/) for notes on the two source articles.

Open `index.html` in any example folder. Most demos include a resizable dashed container—drag its right edge to see the behavior change.

Examples:
1. Conditional Everything
2. CSS State Machine
3. Responsive Personality Card
4. Conditional Shadow
5. Breakpointless App Shell
6. Breakpointless Navigation
7. No-Orphan Layout
8. Conditional Typography
9. Conditional UI Density
10. Overflow Pressure
11. Edge-Aware Component
12. Self-Organizing Dashboard
13. Gradual Shrink, Sudden Stack
14. Zero-Query Radius Snap
15. The Holy Albatross
16. Container-Scoped Albatross
17. Chained Albatross
18. Container Style Queries
19. Shape-Aware Container
20. Animatable Constraint Switch
21. Integer Grid Steps
22. Aspect-Ratio Gallery
23. Shape-Morphing Child


All demos use a consistent dark theme and are designed for direct browser experimentation. Demo 18 uses a checkbox toggle instead of the resizable box; demos 19, 22, and 23 resize on both axes (drag the corner). Demo 22 has four independent stages, one per pattern.
